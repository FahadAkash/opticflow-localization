# OptiFlow Benchmarks

This directory will contain benchmark results and performance analysis.

## Planned Benchmarks (M7)

- **API p95 Latency** — Target: < 300ms (excluding external calls)
- **Diff Engine Throughput** — Blocks/second for various content sizes
- **TM Lookup Latency** — Translation memory query performance
- **AI Translation Latency** — LM Studio response time (p50/p95/p99)
- **Job Processing Throughput** — Jobs/minute under load
- **Worker Concurrency** — Optimal worker count for RTX 3060 Ti 8GB
